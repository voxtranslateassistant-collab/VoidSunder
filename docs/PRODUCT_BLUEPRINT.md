# AegisForge - Product Blueprint

## Visão
Plataforma de validação de segurança ofensiva controlada com aparência de Red Team.

## Módulos
1. Asset Intelligence
2. Policy & Scope
3. Test Orchestrator (com ZAP, Playwright, custom fuzzers)
4. LLM Security Lab
5. Evidence Vault
6. Risk Engine (IA)
7. Reporting

## Fluxo Principal
1. Cadastrar Asset
2. Definir Scope
3. Executar Scan
4. Analisar Findings (IA)
5. Gerar Report + PoC
